# Bot prueba para proyecto final de Metodología de la Investigación
Inicio de prueba de bot financiero

Descripción del proyecto

Este proyecto consiste en el desarrollo de un bot de trading algorítmico en Python, creado con fines académicos. El sistema utiliza datos históricos del mercado financiero para simular operaciones de compra y venta de activos, basándose en una estrategia de cruce de medias móviles (SMA).

El bot descarga información histórica de una acción, calcula indicadores técnicos y genera señales de trading (compra/venta). Posteriormente, simula operaciones utilizando un capital inicial, permitiendo observar el comportamiento de la estrategia sin involucrar dinero real.

Este proyecto es de carácter experimental y forma parte de una entrega académica, por lo que su objetivo principal es demostrar el funcionamiento básico de un sistema automatizado de trading y analizar su desempeño en un entorno controlado.

Este bot no realiza operaciones reales ni garantiza ganancias. Su uso es únicamente educativo y de simulación.
